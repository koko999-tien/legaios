## Interpretation rules

1. Script order is part of the V14 runtime contract because modules are still classic scripts sharing the global lexical environment.
2. A heuristic dependency means a module references a name declared by another module; common words and dynamic property access can create false positives or omissions.
3. Do not reorder scripts solely from this inventory. Use `tools/check-v14-structure.mjs`, CI and browser smoke tests together.
4. Legal-content accuracy is outside this inventory; structural refactoring must not silently rewrite legal data.
5. ES-module conversion should be a separate migration after browser behavior is stable and explicit imports/exports can replace implicit globals.
