## Stage 2b extraction rules

1. Keep classic `<script>` execution order while dependencies remain implicit.
2. Move only complete top-level declarations; do not rewrite legal text/data during structural extraction.
3. For each move, verify the extracted declaration bytes match the original bytes and that the remainder of `app.js` is unchanged except for the removed declaration.
4. Load extracted files before `assets/js/app.js`, then run `tools/check-html.mjs` and Netlify deploy preview.
5. Convert to ES modules only after cross-file dependencies and mutable state are explicit.
